# Tech Stack for 3D Blue Hand Viewer

## Frontend

* HTML5
* CSS3
* JavaScript (ES6 Modules)

## 3D Graphics and Rendering

* Three.js
* WebGL
* OrbitControls

## 3D Model Loading

* GLTFLoader for `.glb` files
* OBJLoader for `.obj` files
* MTLLoader for `.mtl` files

## Assets

* 3D hand model in `.glb` format
* Or `.obj` + `.mtl` model files
* Optional texture image files

## Development Tools

* Visual Studio Code
* Live Server extension
* Python local server using `python -m http.server`

## Optional Tools

* Blender for model editing or format conversion
* Sketchfab, CGTrader, or Free3D for downloading 3D models

## Project Stack Summary

This project uses HTML, CSS, and JavaScript with Three.js on top of WebGL to render and interact with a 3D anatomical hand model in the browser.
